# 🚀 Catálogo de Servicios TI - Municipalidad de Machalí

## 📜 Descripción General

Este proyecto corresponde al sitio web del Catálogo de Servicios de la Unidad de Informática de la Municipalidad de Machalí. Su objetivo es presentar de manera organizada los servicios disponibles, facilitar la navegación entre cada área y permitir a los usuarios acceder a información detallada sobre los distintos apoyos y soluciones que ofrece la unidad.

## 🛠️ Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript

## 🌐 Funcionalidades

- Navegación entre distintas áreas de servicios TI
- Presentación de información detallada por categoría
- Interfaz visual clara y sencilla para usuarios municipales
- Carga dinámica de componentes mediante JavaScript
- Acceso a páginas dedicadas a impresión, redes, telefonía, identidad, continuidad, asesoría y Google Workspace

## 📄 Páginas Principales

- `index.html`: página de inicio del catálogo
- `internet.html`: servicios de internet y redes
- `impresion.html`: servicios de impresión
- `telefonia.html`: servicios de telefonía
- `identidad.html`: gestión de identidad y accesos
- `continuidad.html`: continuidad operacional y soporte técnico
- `workspace.html`: servicios de Google Workspace
- `contacto.html`: información de contacto de la unidad

## ▶️ Cómo Ejecutar

1. Descarga o clona el proyecto en tu equipo.
2. Abre el archivo `index.html` en tu navegador.
3. Si prefieres, puedes usar Live Server en Visual Studio Code para ver el sitio en tiempo real durante el desarrollo.
